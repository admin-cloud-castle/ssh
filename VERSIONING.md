# Версионирование

Проект следует [Semantic Versioning](https://semver.org/lang/ru/).

| Изменение | Версия |
|-----------|--------|
| Ломающий API | MAJOR (`1.0.0` → `2.0.0`) |
| Новая возможность без ломания | MINOR |
| Исправление без API-изменений | PATCH |

До `1.0.0` breaking допустимы в MINOR — фиксируйте в [UPGRADING.md](UPGRADING.md).

Процесс релиза: [RELEASE.md](RELEASE.md).
