# Доступность

Цель: документация и сайт пакета должны быть читаемы с клавиатуры, скринридерами и при увеличении масштаба.

## Известные ограничения

- Основной артефакт — PHP-библиотека (CLI/API), не веб-UI
- Документация в Markdown/HTML на GitHub Pages; визуальная тема зависит от GitHub

## Как сообщить о барьере

1. [Discussions](https://github.com/admin-cloud-castle/ssh/discussions) — вопросы по доступности
2. [Issues](https://github.com/admin-cloud-castle/ssh/issues) с меткой `documentation`
3. Критичные проблемы безопасности интерфейса — через [SECURITY.md](SECURITY.md)

Мы принимаем правки в тексты, разметку wiki и контраст/структуру заголовков.
