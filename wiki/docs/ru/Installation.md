# Installation

Требования: PHP 8.1+, расширения `openssl`, `gmp`. Опционально `pcntl`/`sockets` для ProcessPool.

```bash
composer require cloud-castle/ssh
```

Пакет на Packagist: [cloud-castle/ssh](https://packagist.org/packages/cloud-castle/ssh).
