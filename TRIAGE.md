# Триаж issues

1. Дубликаты — закрыть со ссылкой на оригинал
2. Вопрос без бага — перенести в Discussions
3. Баг — метка `bug`, запросить минимальный repro
4. Фича — метка `enhancement`, связать с [ROADMAP.md](ROADMAP.md)
5. Безопасность — не публично; см. [SECURITY.md](SECURITY.md)
6. `good first issue` — только после ясного описания шагов

Мейнтейнеры: [MAINTAINERS.md](MAINTAINERS.md).
