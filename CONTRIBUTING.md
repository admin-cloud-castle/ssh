# Участие в разработке

Спасибо за интерес к `cloud-castle/ssh`.

## Быстрый цикл

1. Fork + ветка от `main`
2. `composer install`
3. `composer ci` — должно быть зелёным
4. PR с кратким «зачем» (без шаблонных чеклистов)

## Стандарты

- PHP 8.1+, `declare(strict_types=1);`
- PHPDoc на русском у публичного и внутреннего API
- Покрытие ≥99.8%, Infection MSI 100%
- Коммиты: `type: суть` в повелительном наклонении
